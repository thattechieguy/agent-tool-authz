# Branding guide

## Logo file

- Source: `assets/logo.svg`
- Recommended usage in docs/web: SVG directly.

## Exporting PNG

Use any SVG-capable tool (Inkscape, Figma, Illustrator, or browser screenshot at scale).

Suggested sizes:
- 512x171 for social previews
- 256x85 for README badges/cards
